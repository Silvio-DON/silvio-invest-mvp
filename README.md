# 💼 Silvio Invest — MVP de produto

MVP de um produto de **gestão de patrimônio com apoio de IA** para investidores pessoa física, com acompanhamento da carteira em um dashboard.

Este repositório reúne a **fase de produto** do projeto: definição do problema, backlog e protótipos de tela.

## 🖼️ Telas planejadas

1. **Login** e **cadastro**
2. **Ativação de autenticação em dois fatores (2FA)** — segurança desde o início, por lidar com dados financeiros
3. **Dashboard da carteira** — visão consolidada dos investimentos

## 🧭 Metodologia

Scrum: product backlog → sprint backlog → prototipação → validação.
